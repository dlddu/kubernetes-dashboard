# 테스트 문서: 클러스터 오버뷰

> `prd-overview.md`의 AC를 검증하는 테스트 문서.
> 상위: `docs/product/values.md` · 대상 PRD: `prd-overview.md`

## 검증 대상 AC
- OV1 요약 카드 · OV2 비정상 파드 미리보기 · OV3 노드 퀵뷰 · OV4 자동 폴링 · OV5 수동 새로고침 · OV6 네임스페이스 스코프 · OV7 메트릭 폴백

## 테스트 시나리오

### 시나리오 1: 4개 요약 카드 표시
- **사전 조건**: 클러스터에 노드·파드·사용률 데이터 존재.
- **실행 단계**: `/`(오버뷰) 진입 → 요약 카드 4종 확인.
- **기대 결과**: Nodes(ready/total), Unhealthy Pods, Avg CPU(%), Avg Memory(%) 카드가 올바른 레이블·값으로 표시되고, CPU/메모리는 0–100% 범위.
- **검증 AC**: OV1
- **자동화**: `e2e/overview-summary-cards.spec.ts` (OV1 전용)

### 시나리오 2: 비정상 파드 미리보기 (최대 3개)
- **사전 조건**: 비정상 파드가 1개 이상 존재.
- **실행 단계**: 오버뷰에서 미리보기 영역 확인.
- **기대 결과**: 최대 3개의 파드가 이름·네임스페이스·상태 배지와 함께 표시. 없으면 빈 상태.
- **검증 AC**: OV2
- **자동화**: `e2e/unhealthy-pod-preview.spec.ts` (OV2 전용)

### 시나리오 3: 노드 퀵뷰
- **사전 조건**: 노드 존재.
- **실행 단계**: 오버뷰의 노드 퀵뷰 확인.
- **기대 결과**: 노드별 상태·역할·CPU/메모리 사용률이 표시.
- **검증 AC**: OV3
- **자동화**: `e2e/node-quick-view.spec.ts` (OV3 전용)

### 시나리오 4: 자동 폴링 및 일시정지
- **사전 조건**: 오버뷰 표시 중.
- **실행 단계**: 폴링 주기(10초) 경과 후 마지막 갱신 시각 변화 확인 → 탭 비활성화 시 폴링 중단, 재활성화 시 재개 확인.
- **기대 결과**: 주기마다 데이터/시각 갱신, 비가시 상태에서 폴링 멈춤, 복귀 시 재개.
- **검증 AC**: OV4
- **자동화**: `e2e/overview-auto-polling.spec.ts` (OV4 전용)

### 시나리오 5: 수동 새로고침
- **사전 조건**: 오버뷰 표시 중.
- **실행 단계**: 새로고침 버튼 클릭 → 즉시 갱신 및 버튼 비활성(진행 중) 확인.
- **기대 결과**: 즉시 재조회, 진행 중 버튼 비활성, 전체 대시보드 데이터 갱신.
- **검증 AC**: OV5
- **자동화**: `e2e/overview-manual-refresh.spec.ts` (OV5 전용)

### 시나리오 6: 네임스페이스 스코프
- **사전 조건**: 여러 네임스페이스에 파드 존재.
- **실행 단계**: 네임스페이스 변경 → 오버뷰(비정상 파드 집계 등) 갱신 확인.
- **기대 결과**: 선택된 네임스페이스 기준으로 집계(`GET /api/overview?ns=`).
- **검증 AC**: OV6
- **자동화**: `e2e/overview-namespace-scope.spec.ts` (OV6 전용)

### 시나리오 7: 메트릭 서버 부재 시 폴백
- **사전 조건**: metrics-server 비활성 환경.
- **실행 단계**: 오버뷰 진입 → 화면이 정상 렌더되고 사용률이 폴백 값으로 표시되는지 확인.
- **기대 결과**: 빈 화면/에러 없이 capacity-allocatable 기반 폴백 사용률 표시.
- **검증 AC**: OV7
- **자동화**: `e2e/overview-metrics-fallback.spec.ts` (OV7 전용) — metrics-server 부재 kind 프로파일에서 실환경 재현. CI E2E 매트릭스의 `no-metrics` leg가 `INSTALL_METRICS_SERVER=false`로 생성한 전용 클러스터(별도 러너)에서 이 스펙만(`--project=no-metrics`) 실행하므로 metrics 의존 스펙(OV1 등)은 영향받지 않는다. 데이터-모킹 없이(인터셉트 0) 오버뷰가 정상 렌더되고 사용률이 capacity-allocatable 폴백 값으로 표시됨을 단정. 백엔드 폴백 계산은 `handlers/overview_test.go`가 유닛 커버.
