# 테스트 문서: Pods 탭

> `prd-pods.md`의 AC를 검증하는 테스트 문서. 각 시나리오는 대응 e2e 스펙(자동화)에 연결하거나, 자동화 공백을 표시한다.
> 상위: `docs/product/values.md` · 대상 PRD: `prd-pods.md`

## 검증 대상 AC
- PD1 파드 목록 표시(네임스페이스 스코프) · PD2 파드 로그 · PD3 파드 셸(exec) · PD4 ephemeral 디버그 · PD5 실패 파드 정리 · PD6 완료 파드 숨김 · PD7 데이터 상태 처리

## 테스트 시나리오

### 시나리오 1: 파드 목록과 카드 정보 표시
- **사전 조건**: 테스트 네임스페이스에 Running/ImagePullBackOff/CrashLoopBackOff 파드가 존재.
- **실행 단계**: `/pods`로 이동 → "All Pods (N)" 헤더와 파드 카드 그리드 확인.
- **기대 결과**: 각 카드에 파드 이름·네임스페이스·상태 배지·재시작 횟수·노드·age가 표시되고, 상태별 배지 스타일(error/warning)이 적용된다.
- **검증 AC**: PD1
- **자동화**: `e2e/pods.spec.ts` (PD1 전용)

### 시나리오 2: 네임스페이스 스코프 반영
- **사전 조건**: 둘 이상의 네임스페이스에 파드 존재.
- **실행 단계**: 네임스페이스 셀렉터에서 특정 네임스페이스 선택 → 파드 목록 갱신 확인.
- **기대 결과**: 선택된 네임스페이스의 파드만 표시(`GET /api/pods?ns=`).
- **검증 AC**: PD1
- **자동화**: `e2e/pods.spec.ts` (PD1 전용)

### 시나리오 3: 파드 로그 조회
- **사전 조건**: 로그가 있는 파드 존재.
- **실행 단계**: 파드 카드 클릭 → 로그 패널 오픈 → 로그 출력 확인.
- **기대 결과**: 선택 파드의 로그가 실시간으로 표시된다.
- **검증 AC**: PD2, (V6)
- **자동화**: `e2e/pod-logs.spec.ts` (PD2 전용)

### 시나리오 4: 파드 셸(exec) 실행
- **사전 조건**: exec 가능한 Running 파드 존재.
- **실행 단계**: 카드에서 셸 실행 → 터미널 패널 오픈 → 명령 입력/출력, 터미널 리사이즈 확인.
- **기대 결과**: WebSocket 세션으로 입출력이 동작하고 cols/rows 변경이 반영된다.
- **검증 AC**: PD3, (V6)
- **자동화**: `e2e/pod-exec.spec.ts` (PD3 전용)

### 시나리오 5: ephemeral 디버그 컨테이너
- **사전 조건**: 디버그 대상 파드 존재, 권한(정상) 케이스와 RBAC 거부 케이스.
- **실행 단계**: 카드에서 디버그 → 다이얼로그 제출 → 생성된 컨테이너로 셸 오픈 확인. 권한 없을 때 거부 메시지 확인.
- **기대 결과**: 정상 시 ephemeral 컨테이너 생성 후 셸 오픈, 권한 없을 시 RBAC 거부 메시지 표시.
- **검증 AC**: PD4
- **자동화**: `e2e/pod-debug.spec.ts` (PD4 전용)

### 시나리오 6: 실패 파드 정리(cleanup)
- **사전 조건**: completed/failed 등 정리 대상 파드 존재.
- **실행 단계**: "Cleanup Pods (N)" 버튼 클릭 → 빨강 확인 다이얼로그 → 확인 → 삭제 및 목록 갱신. 부분 실패 케이스도 확인.
- **기대 결과**: 확인 후에만 삭제 실행, 부분 실패 시 실패 개수 표시 후 목록 갱신.
- **검증 AC**: PD5
- **자동화**: `e2e/pod-cleanup.spec.ts` (PD5 전용)

### 시나리오 7: 완료 파드 숨김 토글
- **사전 조건**: 완료(succeeded/completed) 파드가 1개 이상 존재.
- **실행 단계**: "Hide Completed (N)" 토글 ON → 완료 파드가 목록에서 사라지는지 확인 → 모두 숨겨지면 안내 메시지 확인.
- **기대 결과**: 토글 상태에 따라 완료 파드가 필터링된다.
- **검증 AC**: PD6
- **자동화**: `e2e/pods-hide-completed.spec.ts` (PD6 전용)

### 시나리오 8: 데이터 상태 처리
- **사전 조건**: 로딩 중 / 조회 실패 / 파드 없음 각 상태.
- **실행 단계**: 각 상태에서 화면 확인.
- **기대 결과**: 스켈레톤 / 재시도 가능한 에러 / 빈 상태 메시지가 표시된다.
- **검증 AC**: PD7
- **자동화**: `e2e/pods-data-states.spec.ts` (PD7 전용)

## 커버리지 요약

- 자동화 공백: 없음
